# Mody Car Wash — منشورات تلقائية شهرية

يولّد شهر كامل من الإعلانات (صورة + نص + هاشتاكات لكل يوم) ويجدولها عبر Buffer
على فيسبوك وانستغرام وجوجل بزنس بروفايل، **الساعة 10:00 صباحاً بتوقيت شرق أمريكا يومياً**.

الكلفة التشغيلية: **صفر**.

---

## مرة واحدة فقط — التجهيز

### 1. Cloudflare (توليد الصور — مجاني، بدون بطاقة)
1. سجّل حساب مجاني على <https://dash.cloudflare.com>
2. من الشريط الجانبي: **AI → Workers AI → Use REST API → Create a Workers AI API Token**
3. انسخ **API Token** و **Account ID**

### 2. Buffer (النشر)
1. تأكد أن مربوط: صفحة فيسبوك + حساب انستغرام **Business** + جوجل بزنس بروفايل
2. من <https://publish.buffer.com/settings/api> → **New Key** → صلاحية **سنة واحدة**
3. انسخ المفتاح

> المفتاح صالح لسنة كحد أقصى. حط تذكير بالتقويم بعد 11 شهر للتجديد.

### 3. GitHub
1. أنشئ مستودع **public** (لازم public حتى تشتغل استضافة الصور مجاناً) وارفع هذا المجلد
2. **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `root`** → Save
3. **Settings → Secrets and variables → Actions → Secrets** أضف:
   - `BUFFER_API_KEY`
   - `CF_ACCOUNT_ID`
   - `CF_API_TOKEN`
4. نفس الصفحة → تبويب **Variables** (اختياري):
   - `TARGET_QUEUE` = `7` (كم منشور يبقى بالطابور لكل قناة؛ السقف المجاني 10)
   - `PAGES_BASE_URL` فقط إذا تستخدم دومين مخصص

## حدود الطبقة المجانية

Cloudflare يعطي **10,000 نيورون يومياً** مجاناً. الشهر الكامل (30 صورة + 30 ريل)
يستهلك تقريباً **6,000** — يعني يدخل بحصة يوم واحد.

النظام يوقف نفسه عند **8,500 نيورون** (`NEURON_BUDGET`) قبل ما يصل الحد، ويحفظ شغله
ويكمل بالتشغيل الجاي. وحارس الحروف يفحص نسخة مصغّرة 448px من الصورة بدل الأصلية —
يوفر ~89% من كلفته بدون ما يفقد قدرته على رؤية كتابة واضحة.
إذا نفدت الحصة، التوليد **يتوقف بهدوء ويحفظ كل شي أنجزه** — وworkflow مجدول يشتغل
يومياً الساعة 00:20 UTC (بعد تجديد الحصة مباشرة) ويكمّل من مكانه بدون أي تدخل منك.

## الاستخدام الشهري — الزر

**Actions → Generate Monthly Posts → Run workflow**

يولّد الشهر الجاي كامل (~30 منشور)، يحفظ الصور، ويسوي commit تلقائي.
بعدها راجع النتيجة على:

```
https://<حسابك>.github.io/<المستودع>/posts/YYYY-MM/index.html
```

الروبوت اليومي (`Daily Buffer Top-Up`) يشتغل لحاله كل صباح ويعبّي طابور Buffer.
أنت ما تسوي شي غير الزر مرة بالشهر.

## الريلز — منشور ثاني كل يوم

| | الصبح | العصر |
|---|---|---|
| النوع | صورة ثابتة | ريل 10 ثواني بموسيقى |
| الوقت | 10:00 ص شرق أمريكا | 8:00 م شرق أمريكا |
| المقاس | 1080×1350 | 1080×1920 عمودي |
| القنوات | فيسبوك + انستغرام + جوجل | فيسبوك + انستغرام فقط |

الريل يُبنى بالكامل داخل Chromium: كل إطار دالة صافية من الزمن (`window.__seek(t)`)،
يعني النتيجة مطابقة كل مرة ومو تسجيل شاشة. بعدين FFmpeg يجمع 300 إطار مع مقطع
موسيقى خالي الحقوق من `templates/music/`.

**الموسيقى:** انستغرام **لا يسمح** بإضافة مكتبته الموسيقية عبر API — فقط من داخل التطبيق.
وحسابات الأعمال ممنوعة أصلاً من الأغاني الرائجة. لذلك الصوت مدمج بالملف من مقاطع
خالية الحقوق (Pixabay). لا تضيف موسيقى تجارية — انستغرام يكتم الفيديو تلقائياً.

```bash
npm run reels                     # يبني ريلز الشهر
node scripts/reel-preview.mjs     # يبني ريل واحد للمعاينة
node scripts/cleanup.mjs          # يحذف الوسائط الأقدم من 60 يوم
```

**التنظيف التلقائي:** كل ريل 1.5–3 ميغا. سكربت `cleanup.mjs` يشتغل مع كل بناء ويحذف
أي ملف مضى على نشره 60 يوم، حتى ما يتضخم المستودع ويتجاوز سقف GitHub Pages.

## كيف يشتغل

| المرحلة | الأداة | التفصيل |
|---|---|---|
| توليد الصورة | Cloudflare Workers AI (FLUX.1 schnell) | مجاني، ~170 صورة/يوم، رخصة Apache-2.0 تجارية |
| منع التكرار | مصفوفة 153,600 تركيبة + بصمة pHash | `data/history.json` يمنع أي إعادة استخدام |
| التصميم والكتابة | Chromium + HTML/CSS | النص **لا يُولّد** بالذكاء الاصطناعي — يُطبع بخط Manrope وألوان الهوية |
| الاستضافة | GitHub Pages | Buffer يسحب الصورة من الرابط لحظة النشر، فلازم يبقى حي |
| حارس الحروف | Llama 3.2 Vision على Cloudflare | يفحص كل صورة ويرفضها إذا الموديل رسم حروف مشوّهة، ويعيد التوليد تلقائياً |
| الجدولة | Buffer GraphQL API | `mode: customScheduled` بتوقيت UTC محسوب من 10:00 ET مع التوقيت الصيفي |

ثلاثة تخطيطات تتناوب: `panel` / `scrim` / `glass`.
مقاسان: `1080×1350` لفيسبوك وانستغرام، `1080×1080` لجوجل بزنس.

### زر "احجز" وروابط الموقع

| المنصة | شنو ينزل |
|---|---|
| جوجل بزنس | زر **Book** حقيقي يودّي مباشرة للموقع |
| فيسبوك | الرابط بالنص وهو قابل للضغط (التعليق التلقائي ميزة مدفوعة بـ Buffer — فعّلها بـ `BUFFER_FIRST_COMMENT=1` لو اشتركت) |
| انستغرام | رابط البايو فقط — انستغرام لا يسمح بروابط قابلة للضغط بمنشورات الفيد إطلاقاً |

**تنبيه انستغرام:** علامة "AI info" مو مفعّلة — النظام ما يصرّح بشي إطلاقاً (ما يقول الصور مولّدة ولا يقول العكس). Meta ممكن تكتشفها وتضيف العلامة لحالها. للتصريح الصريح ضيف متغير `AI_LABEL=on`.

### قواعد مفروضة بالكود
- **إزالة التظليل فقط** — لا يُعلن عن تركيب تظليل إطلاقاً
- **لا أرقام هاتف في نصوص جوجل بزنس** (سياسة جوجل)
- **لا شعارات سيارات ولا لوحات أرقام** في الصور (حماية من العلامات التجارية)
- **لا أسعار** في الإعلانات — السعر يتأكد عند الحجز
- منشورات الأحد تستخدم صيغة "مغلق اليوم" لأن المحل مغلق

```bash
npm run doctor                     # فحص المفاتيح والقنوات والطابور
MONTH=2026-11 npm run generate -- --dry-run   # يعرض خطة الشهر بدون توليد صور
npm run topup -- --dry-run         # يعرض شنو راح ينجدول بدون ما ينشر
```

## إذا صار خلل

| العرض | السبب والحل |
|---|---|
| `no instagram channel connected` | أعد ربط انستغرام في Buffer، ولازم يكون حساب Business |
| `image not reachable` | GitHub Pages مو مفعّل، أو المستودع private |
| `at the free-plan cap` | الطابور وصل 10؛ الروبوت اليومي راح يكمل تلقائياً بعد ما ينشر منشور |
| `Buffer GraphQL: ...` | غالباً المفتاح انتهت صلاحيته — أنشئ مفتاح جديد وحدّث الـ Secret |

**مهم:** لا تحذف ولا تعيد تسمية أي ملف داخل `posts/` قبل ما ينشر — Buffer يسحب الصورة
لحظة النشر مو لحظة الجدولة، وأي رابط ميت يفشل المنشور بصمت.
